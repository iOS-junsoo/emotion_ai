## 전체 아키텍처

```
[클라이언트 (브라우저)]
    │
    ├─ 웹캠: 1초당 1프레임 캡처 → WebSocket 전송
    ├─ 마이크: 휴지기 기반 음성 청크 → WebSocket 전송
    ├─ 발화 완료 버튼 or 긴 휴지기 감지 → 완료 신호
    │
    └─ WebSocket ──────────────────────────────────┐
                                                   │
                                          [백엔드 서버 (FastAPI)]
                                                   │
                          ┌────────────────────────┼──────────────────┐
                          │                        │                  │
                  [얼굴 감정 모듈]          [음성 수집 모듈]         (대기)
                  프레임 수신할 때마다       청크 수신할 때마다
                  → DeepFace 분석          → 전체 오디오에 합치기
                  → 얼굴 감정 버퍼에 저장   → 오디오 버퍼에 누적
                          │                        │                  
                          │                        │                  
                    [발화 완료 신호 수신]───────────┘                  
                          │                                          
                          ├─ 얼굴: 버퍼 감정 집계 (평균)              
                          ├─ 음성: 전체 오디오 → wav2vec2 → 감정 추출  
                          ├─ 텍스트: 전체 오디오 → Whisper STT         
                          │          → 텍스트 → klue/bert → 감정 추출 
                          │                                          
                          ├─ fusion.py → 최종 감정                    
                          ├─ 감정별 LoRA 스위칭                       
                          ├─ LLM 응답 생성                            
                          │                                          
                          └─ WebSocket → 클라이언트에 응답 전송        
```

## 모듈별 상세 설계

### 1. 클라이언트 (브라우저)
- **영상**: MediaStream API로 웹캠 → 1초당 1프레임 base64로 WebSocket 전송
- **음성**: MediaRecorder API로 마이크 → 휴지기 기반 청크 WebSocket 전송
- **발화 완료**: 버튼 클릭 or 긴 휴지기(2초 이상) 감지 시 완료 신호 전송
- **UI**: 상담 채팅 인터페이스 + 감정 상태 표시

### 2. WebSocket 서버
- **프레임워크**: FastAPI + WebSocket
- **메시지 타입**:
  - `video_frame`: 영상 프레임 (base64 이미지) → 실시간 처리
  - `audio_chunk`: 음성 청크 (base64 오디오) → 오디오 버퍼에 누적
  - `user_done`: 사용자 발화 완료 신호 → 전체 처리 시작
  - `bot_response`: LLM 응답 + 감정 정보

### 3. 얼굴 감정 모듈 (실시간 처리)
```python
class FaceEmotionBuffer:
    """발화 중 1초마다 프레임을 받아 감정을 버퍼에 쌓음"""

    def __init__(self):
        self.buffer = []  # [(timestamp, emotion_scores), ...]

    def process_frame(self, frame_base64):
        """프레임 수신할 때마다 호출"""
        frame = decode_base64_to_image(frame_base64)
        result = DeepFace.analyze(frame, actions=['emotion'],
                                  enforce_detection=False, silent=True)
        scores = result[0]['emotion']  # {'happy': 80, 'sad': 5, ...}
        self.buffer.append((time.time(), scores))

    def get_aggregated_emotion(self):
        """발화 완료 시 호출 - 버퍼의 감정 평균 계산"""
        if not self.buffer:
            return None
        avg_scores = {}
        for emo in ['happy', 'sad', 'angry', 'surprise', 'fear', 'disgust', 'neutral']:
            avg_scores[emo] = sum(b[1][emo] for b in self.buffer) / len(self.buffer)
        self.buffer.clear()
        return avg_scores
```

### 4. 음성 수집 모듈 (발화 중 누적, 완료 후 한번에 처리)
```python
class VoiceProcessor:
    """발화 중 음성 청크를 누적하고, 완료 후 전체 오디오로 감정 추출"""

    def __init__(self):
        self.audio_chunks = []  # 음성 청크 누적
        self.emotion_model = load_wav2vec2_model()  # wav2vec2-xlsr

    def add_chunk(self, audio_chunk_base64):
        """음성 청크 수신할 때마다 호출 - 누적만 함"""
        chunk = decode_base64_to_audio(audio_chunk_base64)
        self.audio_chunks.append(chunk)

    def get_full_audio(self):
        """전체 오디오 반환"""
        full_audio = combine_audio_chunks(self.audio_chunks)
        return full_audio

    def get_emotion(self):
        """발화 완료 시 호출 - 전체 오디오로 감정 한번에 추출"""
        full_audio = self.get_full_audio()
        probs = self.emotion_model.predict(full_audio)  # 7개 감정 확률
        self.audio_chunks.clear()
        return probs
```

### 5. 텍스트 감정 모듈 (발화 완료 후 처리)
```python
class TextProcessor:
    """전체 오디오 → STT → 텍스트 감정 추출"""

    def __init__(self):
        self.stt_model = load_whisper_model()  # Whisper
        self.emotion_model = load_text_emotion_model()  # klue/bert

    def process(self, full_audio):
        """발화 완료 시 호출 - STT + 감정 추출"""
        # 1. Whisper STT
        text = self.stt_model.transcribe(full_audio)

        # 2. klue/bert 감정 분석
        probs = self.emotion_model.predict(text)  # 7개 감정 확률

        return text, probs
```

### 6. 상담 세션 (전체 흐름 관리)
```python
class CounselingSession:
    def __init__(self):
        self.face_buffer = FaceEmotionBuffer()
        self.voice_processor = VoiceProcessor()
        self.text_processor = TextProcessor()
        self.fusion = EmotionFusion()
        self.llm = load_cbt_llm()
        self.current_lora = None
        self.chat_history = []
        self.emotion_history = []  # 턴별 감정 변화 기록

    async def on_video_frame(self, frame_base64):
        """영상 프레임 수신 시 (실시간)"""
        self.face_buffer.process_frame(frame_base64)

    async def on_audio_chunk(self, audio_chunk_base64):
        """음성 청크 수신 시 (누적만)"""
        self.voice_processor.add_chunk(audio_chunk_base64)

    async def on_user_done(self):
        """사용자 발화 완료 시"""

        # 1. 전체 오디오 가져오기
        full_audio = self.voice_processor.get_full_audio()

        # 2. 얼굴 감정: 버퍼에 쌓인 것 평균
        face_emotion = self.face_buffer.get_aggregated_emotion()

        # 3. 음성 감정: 전체 오디오로 한번에 추출
        voice_emotion = self.voice_processor.get_emotion()

        # 4. 텍스트: 전체 오디오 → STT → 감정 추출
        user_text, text_emotion = self.text_processor.process(full_audio)

        # 5. 멀티모달 융합 → 최종 감정
        result = self.fusion.fuse(
            text_probs=text_emotion,
            voice_probs=voice_emotion,
            face_probs=face_emotion,
        )
        final_emotion = result['emotion']

        # 6. 감정 변화 기록
        self.emotion_history.append({
            'turn': len(self.chat_history) // 2 + 1,
            'emotion': final_emotion,
            'scores': result['scores'],
            'modality': result['modality_emotions'],
            'conflict': result['conflict'],
        })

        # 7. 감정별 LoRA 스위칭
        if final_emotion != self.current_lora:
            self.llm.switch_lora(final_emotion)
            self.current_lora = final_emotion

        # 8. LLM 응답 생성
        self.chat_history.append({"role": "user", "content": user_text})
        response = self.llm.generate(self.chat_history, emotion=final_emotion)
        self.chat_history.append({"role": "assistant", "content": response})

        # 9. 결과 반환
        return {
            "response": response,
            "emotion": final_emotion,
            "emotion_scores": result['scores'],
            "conflict": result['conflict'],
            "user_text": user_text,
        }
```

## 데이터 흐름 타임라인 (1턴)

```
시간 →

[사용자 발화 시작]
  │
  ├─ 0s: 웹캠 프레임 → DeepFace → 얼굴 버퍼 저장
  │       음성 청크 → 오디오 버퍼에 누적
  │
  ├─ 1s: 웹캠 프레임 → DeepFace → 얼굴 버퍼 저장
  │       음성 청크 → 오디오 버퍼에 누적
  │
  ├─ 2s: 웹캠 프레임 → DeepFace → 얼굴 버퍼 저장
  │       음성 청크 → 오디오 버퍼에 누적
  │
  ├─ 3s: 웹캠 프레임 → DeepFace → 얼굴 버퍼 저장
  │       음성 계속 누적...
  │
[사용자 발화 완료] (버튼 클릭 or 2초 이상 침묵)
  │
  ├─ 얼굴: 버퍼 4개 프레임 감정 → 평균 계산
  ├─ 음성: 누적된 전체 오디오 → wav2vec2 → 감정 1번 추출
  ├─ 텍스트: 전체 오디오 → Whisper STT → klue/bert → 감정 추출
  │
  ├─ fusion(얼굴, 음성, 텍스트) → 최종 감정
  ├─ LoRA 스위칭 → LLM 응답 생성
  │
[상담사 응답 전송] (~2~5초 소요)
```

## 기술 스택

| 구성요소 | 기술 | 비고 |
|---------|------|------|
| 백엔드 | FastAPI + WebSocket | 비동기 처리 |
| 프론트엔드 | HTML/JS + MediaStream API | 웹캠 + 마이크 |
| 얼굴 감정 | DeepFace (84%) | 실시간 처리 |
| 음성 감정 | wav2vec2-xlsr (86%) | 발화 완료 후 1회 |
| 텍스트 감정 | klue/bert-base (93%) | 발화 완료 후 1회 |
| STT | Whisper (로컬) | 발화 완료 후 1회 |
| 감정 융합 | fusion.py | 가중치: 텍스트 0.40 + 음성 0.35 + 얼굴 0.25 |
| LLM | Qwen 2.5 3B + CBT LoRA + 감정별 LoRA | LoRA 동적 스위칭 |
| VAD | 클라이언트 측 휴지기 감지 | 2초 이상 침묵 = 발화 완료 |

## 처리 시점 정리

| 모듈 | 발화 중 | 발화 완료 후 |
|------|--------|------------|
| 얼굴 | ✅ 1초마다 감정 추출 → 버퍼 저장 | 버퍼 평균 계산 |
| 음성 | 청크 누적만 (감정 추출 안 함) | ✅ 전체 오디오 → 감정 1회 추출 |
| 텍스트 | 처리 안 함 | ✅ 전체 오디오 → STT → 감정 추출 |
