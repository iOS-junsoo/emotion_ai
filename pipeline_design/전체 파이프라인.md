# 전체 파이프라인 흐름도

## 1단계: 사용자 초기 데이터 입력

```
[프론트엔드 - 상담 시작 화면]

  STEP 1/4: 어떤 분야의 상담을 원하세요?
  → 사용자 선택: "직장 스트레스"

  STEP 2/4: 현재 감정은 어떠세요?
  → 사용자 선택: "분노"

  STEP 3/4: 구체적으로 어떤 상황인가요?
  → 사용자 입력: "상사가 제 성과를 자기 것처럼 가져가요"

  STEP 4/4: 상담 시작
  → [시작하기] 버튼 클릭
```

## 2단계: 백엔드 → AI → 5-Step 플랜 생성

```
[프론트엔드]                         [백엔드 (FastAPI)]                    [AI (Qwen + CBT LoRA)]
    │                                     │                                     │
    ├─ WebSocket 연결 ───────────────────→│                                     │
    │                                     │                                     │
    ├─ initial_data 전송 ────────────────→│                                     │
    │  {                                  │                                     │
    │    topic: "직장 스트레스",           │                                     │
    │    emotion: "분노",                 ├─ StepManager 생성 ────────────────→│
    │    detail: "상사가 제 성과를..."     │   (topic, emotion, detail)          │
    │  }                                  │                                     │
    │                                     │                                     │
    │                                     │   5-Step 플랜 생성 (고정 템플릿)     │
    │                                     │   + 감정별 LoRA 로드 (분노 LoRA)     │
    │                                     │   + Step 1 상담사 첫 발화 생성       │
    │                                     │                                     │
    │                                     │←─ 플랜 JSON + 첫 발화 반환 ─────────┤
    │←─ 플랜 + 첫 발화 전달 ──────────────┤                                     │
    │                                     │                                     │
    ├─ 사이드바에 5-Step 표시              │                                     │
    │   ● 1. 공감 형성  ◀                 │                                     │
    │   ○ 2. 문제 탐색                    │                                     │
    │   ○ 3. 사고 전환                    │                                     │
    │   ○ 4. 행동 계획                    │                                     │
    │   ○ 5. 마무리                       │                                     │
    │                                     │                                     │
    ├─ 채팅창에 상담사 첫 발화 표시        │                                     │
    │   "안녕하세요. 직장에서 많이         │                                     │
    │    힘드셨나 봐요. 편하게             │                                     │
    │    이야기해주세요."                  │                                     │
    │                                     │                                     │
    ├─ 웹캠 + 마이크 활성화               │                                     │
    │                                     │                                     │
    [상담 시작 - 사용자 발화 대기]          │                                     │
```

## 3단계: 턴별 감정 추출 및 LoRA 적용 (반복)

```
═══════════════════════════════════════════════════════════════
  턴 N 시작: 사용자 발화 중
═══════════════════════════════════════════════════════════════

[프론트엔드]                         [백엔드 (FastAPI)]
    │                                     │
    │  ── 사용자 발화 중 ──                │
    │                                     │
    ├─ 1초마다 웹캠 프레임 ──────────────→│
    │  (video_frame: base64)              ├─ DeepFace 분석
    │                                     ├─ 얼굴 감정 → 얼굴 버퍼에 저장
    │                                     │  buffer: [{t:0s, happy:5, angry:80, ...},
    │                                     │           {t:1s, happy:3, angry:85, ...},
    │                                     │           {t:2s, happy:4, angry:78, ...}]
    │                                     │
    ├─ 음성 청크 (휴지기 기반) ──────────→│
    │  (audio_chunk: base64)              ├─ 오디오 버퍼에 누적 (감정 추출 안 함)
    │                                     │  audio_buffer: [chunk1, chunk2, chunk3, ...]
    │                                     │
    │                                     │
    │  ── 사용자 발화 완료 ──              │
    │  (2초 침묵 or 버튼 클릭)             │
    │                                     │
    ├─ user_done 신호 ──────────────────→│
    │                                     │
    │                                     │

═══════════════════════════════════════════════════════════════
  턴 N: 발화 완료 → 감정 추출 → LLM 응답
═══════════════════════════════════════════════════════════════

                                    [백엔드]
                                        │
                                  전체 오디오 합치기 (~0.05초)
                                        │
                    ┌───────────────────┼───────────────────┐
                    │                   │                   │
                    │            ┌──────┴──────┐            │
                    │            │             │            │
            [1. 얼굴 감정]  [2. Whisper STT] [3. 음성 감정]  │
            (버퍼 평균 계산)  (small 모델)   (wav2vec2-xlsr)  │
            ~0.01초         ~1초           ~0.5초           │
                    │            │             │            │
                    │            ▼             │            │
                    │     [4. 텍스트 감정]      │            │
                    │     (klue/bert)          │            │
                    │     ~0.1초               │            │
                    │            │             │            │
                    └────────────┼─────────────┘
                                 │
                          ※ 2+4와 3은 병렬 처리
                          ※ 2→4는 순차 (STT 결과 필요)
                          ※ 병렬 구간 소요: ~1.1초
                                 │
                                 ▼
                        ┌──────────────────┐
                        │  fusion.py 융합   │  ~0.01초
                        │                  │
                        │  텍스트 × 0.40   │
                        │  음성   × 0.35   │
                        │  얼굴   × 0.25   │
                        │                  │
                        │  → 최종: angry   │
                        │  충돌 감지: 없음  │
                        └────────┬─────────┘
                                 │
                                 ▼
                    ┌──────────────────────┐
                    │  LoRA 스위칭 판단     │  0초 (유지) or ~1~3초 (변경 시)
                    │                      │
                    │  이전 LoRA: angry     │
                    │  현재 감정: angry     │
                    │  → 동일하므로 유지    │
                    │                      │
                    │  (만약 sad로 바뀌면   │
                    │   angry LoRA 해제 →   │
                    │   sad LoRA 로드)      │
                    └────────┬─────────────┘
                             │
                             ▼
                    ┌──────────────────────┐
                    │  LLM 응답 생성        │  ~1.5~2.5초 (vLLM 서빙)
                    │                      │
                    │  시스템 프롬프트:      │
                    │  - 현재 스텝 지시     │
                    │  - 감정: angry        │
                    │  - 턴 수 힌트         │
                    │                      │
                    │  + 대화 히스토리      │
                    │  + 사용자 텍스트      │
                    │                      │
                    │  → 응답 생성          │
                    └────────┬─────────────┘
                             │
                             ▼

  ┌─────────────────────────────────────────────────┐
  │  처리 시간 요약 (3060 Ti 기준)                    │
  │                                                 │
  │  오디오 합치기          ~0.05초                   │
  │  병렬 처리 구간         ~1.1초                    │
  │    ├─ [A] Whisper small STT  ~1초                  │
  │    │      → klue/bert        ~0.1초                │
  │    └─ [B] wav2vec2 음성감정  ~0.5초  (A와 병렬)     │
  │  얼굴 버퍼 평균          ~0.01초                    │
  │  fusion 계산             ~0.01초                    │
  │  LoRA 스위칭             0초 (유지) / ~1~3초        │
  │  LLM 응답 생성 (vLLM)   ~1.5~2.5초                 │
  │                                                   │
  │  ─────────────────────────────────                 │
  │  총 소요 (감정 유지):    ~3~4초                     │
  │  총 소요 (LoRA 변경):    ~4~7초                     │
  │  평균 예상:              ~4초                       │
  └─────────────────────────────────────────────────┘
                             │
                             ▼
                    ┌──────────────────────┐
                    │  스텝 전환 감지        │
                    │                      │
                    │  응답에 "넘어가볼까요" │
                    │  포함? → transition   │
                    │  _proposed = True     │
                    └────────┬─────────────┘
                             │
                             ▼
                    ┌──────────────────────┐
                    │  감정 히스토리 기록    │
                    │                      │
                    │  turn: 1             │
                    │  emotion: angry      │
                    │  scores: {...}       │
                    │  modality: {         │
                    │    face: angry,      │
                    │    voice: angry,     │
                    │    text: angry       │
                    │  }                   │
                    └────────┬─────────────┘
                             │
                             ▼
                        [백엔드 → 프론트]
                             │
                    ┌──────────────────────┐
                    │  WebSocket 응답       │
                    │  {                   │
                    │    response: "...",   │
                    │    emotion: "angry",  │
                    │    step: 1,          │
                    │    step_name: "공감   │
                    │      형성",          │
                    │    step_turns: "1/5", │
                    │    user_text: "...",  │
                    │    plan: {...}        │
                    │  }                   │
                    └────────┬─────────────┘
                             │
                             ▼
                    [프론트엔드]
                    ├─ 채팅창에 상담사 응답 표시
                    ├─ 감정 상태 업데이트 (angry 표시)
                    ├─ 사이드바 스텝 정보 업데이트
                    │
                    [다음 턴 대기 → 턴 N+1 반복]


═══════════════════════════════════════════════════════════════
  스텝 전환이 일어나는 경우 (예: Step 1 → Step 2)
═══════════════════════════════════════════════════════════════

  [이전 턴에서 LLM이 "다음 단계로 넘어가볼까요?" 제안함]
  [transition_proposed = True]

  사용자: "네" (발화 완료)
      │
      ▼
  [감정 추출 과정 동일: 얼굴/음성/텍스트 → fusion → 최종 감정]
      │
      ▼
  check_user_response_for_transition("네") → True
      │
      ▼
  advance_step()
  ├─ Step 1 status: "completed"
  ├─ Step 2 status: "active"
  └─ current_step: 2
      │
      ▼
  generate_step_opening(step=2, emotion=현재감정)
  ├─ Step 2 상담사 첫 발화 생성
  └─ "지금까지 이야기를 들으면서 정말 힘드셨겠다는
      생각이 들었어요. 조금 더 구체적으로 살펴볼게요."
      │
      ▼
  [프론트엔드]
  ├─ 채팅창에 상담사 첫 발화 표시
  ├─ 사이드바 업데이트:
  │   ✓ 1. 공감 형성
  │   ● 2. 문제 탐색  ◀
  │   ○ 3. 사고 전환
  │   ○ 4. 행동 계획
  │   ○ 5. 마무리
  │
  [다음 턴 대기]


═══════════════════════════════════════════════════════════════
  감정 변화로 LoRA 스위칭이 일어나는 경우
═══════════════════════════════════════════════════════════════

  Step 2, 턴 2에서:

  사용자: "솔직히... 제가 부족한 건가 싶기도 해요" (발화 완료)
      │
      ▼
  [얼굴 버퍼]          [음성]              [텍스트]
  평균: sad:60%        전체 오디오 →        Whisper STT →
        angry:20%      wav2vec2 →           klue/bert →
                       sad:0.6              sad:0.7
      │                    │                    │
      └────────────────────┼────────────────────┘
                           ▼
                    fusion: 최종 감정 = sad
                    (텍스트 0.7×0.4 + 음성 0.6×0.35 + 얼굴 0.6×0.25)
                           │
                           ▼
                    LoRA 스위칭!
                    ├─ angry LoRA 해제
                    └─ sad LoRA 로드
                           │
                           ▼
                    LLM 응답 생성 (sad LoRA 적용)
                    시스템 프롬프트에 "내담자의 현재 감정: sad"
                           │
                           ▼
                    상담사: "그런 생각이 드시는군요.
                            많이 힘드셨을 것 같아요.
                            언제부터 그렇게 느끼셨나요?"
                    (← sad LoRA이므로 부드럽고 따뜻한 어투)


═══════════════════════════════════════════════════════════════
  Step 5 완료 → 리포트 생성
═══════════════════════════════════════════════════════════════

  [Step 5 마무리 완료]
      │
      ▼
  generate_report()
  {
    topic: "직장 스트레스",
    emotion_timeline: [
      {turn:1, emotion:"angry", step:1},
      {turn:2, emotion:"angry", step:1},
      {turn:3, emotion:"sad",   step:2},
      {turn:4, emotion:"sad",   step:2},
      {turn:5, emotion:"sad",   step:3},
      {turn:6, emotion:"neutral", step:3},
      {turn:7, emotion:"neutral", step:4},
      {turn:8, emotion:"happy",   step:5},
    ],
    summary: {
      main_concern: "상사의 부당한 대우와 성과 가로채기",
      automatic_thoughts: "'나는 무능하다', '아무도 나를 인정하지 않는다'",
      new_perspectives: "'상사의 태도는 내 능력과 별개', '동료들은 나를 인정한다'",
      action_plan: "이번 주 퇴근 시간 지키기, 동료에게 감사 표현하기",
    },
    emotion_change: {start: "angry", end: "happy"},
    total_turns: 8,
  }
      │
      ▼
  [프론트엔드]
  ├─ 감정 변화 그래프 표시 (angry → sad → neutral → happy)
  ├─ 상담 요약 표시
  ├─ 행동 지침 표시
  └─ 상담 종료
```
